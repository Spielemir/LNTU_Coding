# 🎓 LNTU_Coding

Це репозиторій для моїх практичних робіт з університету.
Тут я зберігаю всі завдання, які виконую протягом навчання, щоб:

* мати зручний доступ до них з будь-якого місця
* продемонструвати виконану роботу викладачам

## 📂 Структура репозиторію

Кожна папка відповідає окремій темі або практичному завданню.
Усередині можуть бути:

* вихідний код
* супровідні файли

## 💡 Навіщо цей репозиторій?

* Зручність зберігання робіт онлайн.
* Можливість швидко показати результат.
* Організованість та порядок у навчальних завданнях.
* Трішки практики з GitHub.

## 🚀 Як користуватися

1. Відкрити потрібну директорію з практичною.
2. Ознайомитися з кодом або завданням.
3. За потреби — завантажити/запустити локально.
